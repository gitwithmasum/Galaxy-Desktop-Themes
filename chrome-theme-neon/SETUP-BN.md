# Masum Galaxy Neon — Chrome Theme

Tab strip-এর deep-space gradient, সূক্ষ্ম cyan/violet glow এবং dark toolbar। Avenger Galaxy New Tab extension-এর সঙ্গে একসঙ্গে ব্যবহার করা যায়। Background ছবি স্থির থাকবে; Chrome-এর নিজস্ব tabs ও address bar-এর আকার বদলাবে না।

## Install

1. ZIP extract করে `Masum-Galaxy-Neon-Chrome-Theme` folder স্থায়ী জায়গায় রাখুন।
2. `chrome://extensions` খুলে **Developer mode** চালু করুন।
3. আগে **Masum Galaxy Glass** বা অন্য theme থাকলে Chrome Settings → Appearance → Theme → **Reset to default** করুন।
4. **Load unpacked** দিয়ে নতুন folder বেছে নিন। Avenger Galaxy New Tab extension-টি চালু রাখতে পারেন।
5. সরাতে Settings → Appearance → Theme → **Reset to default**।

Chrome theme শুধু browser frame, tab strip ও toolbar-এর সমর্থিত রং এবং static image বদলায়। Animation, tab shape, omnibox border ও Windows-এর window buttons নিয়ন্ত্রণ করতে পারে না।
