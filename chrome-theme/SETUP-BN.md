# Masum Galaxy Glass — Chrome browser theme

এই theme Chrome-এর **tab strip, toolbar, address bar এবং text-এর রং** galaxy palette-এ সাজায়। MacBook-এর মতো নরম, dark-glass অনুভূতি দেয়। `Avenger Galaxy` বা অন্য New Tab extension-এর সঙ্গে একসঙ্গে ব্যবহার করা যায়; এটি আলাদা Chrome **theme**।

## লাগানোর ধাপ

1. ZIP extract করুন। ভিতরের `Masum-Galaxy-Glass-Chrome-Theme` folder-এ `manifest.json` এবং `images` folder আছে কি না দেখুন।
2. Chrome-এ `chrome://extensions` খুলে উপরের **Developer mode** অন করুন।
3. **Load unpacked** দিয়ে `Masum-Galaxy-Glass-Chrome-Theme` folder বেছে নিন। Chrome সঙ্গে সঙ্গে tab ও toolbar-এর রং বদলাবে।
4. পছন্দ না হলে **Settings → Appearance → Theme → Reset to default** চাপুন। আবার লাগাতে `chrome://extensions` থেকে theme reload করুন।

**Chrome-এর সীমা:** Windows-এর minimize/maximize/close buttons macOS-এর traffic-light buttons হবে না। Chrome theme address bar-এর shape, tab layout বা সত্যিকারের background blur নিয়ন্ত্রণ করে না। Chrome update ও OS-এর visual settings অনুযায়ী কিছু রং সামান্য আলাদা দেখাতে পারে।

Source: https://developer.chrome.com/docs/extensions/develop/ui/themes
