# Galaxy 12 Worlds — animated laptop wallpaper

Chrome New Tab-এর সেই একই ১২টি scene: Moon, Earth orbit, Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune, Sun, Satellite। প্রতি **৫ সেকেন্ডে** নতুন দৃশ্য আসে; transition, ধীরে zoom এবং ছোট চলমান তারা আছে। নিচে ছোট করে MASUM BILLAH লেখা। ইন্টারনেট ছাড়াই চলে।

## Windows-এ সেট করুন

1. [Lively Wallpaper](https://github.com/rocksdanister/lively) Microsoft Store অথবা এর official GitHub release থেকে install করুন।
2. এই ZIP **extract** করুন। পুরো `Galaxy-12-Worlds` folder একই জায়গায় রাখুন; `scenes` folder আলাদা করলে ছবি দেখা যাবে না।
3. Lively খুলে **Add Wallpaper** (`+`) চাপুন; extracted folder-এর `index.html` file নির্বাচন করুন বা Lively window-তে drag করুন। Import হলে library-তে wallpaper-টি বেছে monitor-এ apply করুন।
4. Browser-এ `index.html` ডাবল ক্লিক করে আগে preview-ও দেখতে পারবেন।

### যদি শুধু কালো background আসে

- `index.html`-এর পাশে `scenes` folder এবং তার ১২টি JPG আছে কি না দেখুন।
- Lively-তে import করার পরও সমস্যা হলে wallpaper remove করে আবার extracted `index.html` যোগ করুন।
- Performance settings-এ fullscreen app চলাকালে pause রাখলে gaming-এর সময় resource কম লাগবে।

### বন্ধ বা পরিবর্তন

Lively-তে অন্য wallpaper বেছে নিন অথবা app Exit করুন। Windows **Settings → Personalization → Background** থেকে স্থির wallpaper দিতে পারবেন। এটি Windows lock screen-এর animation নয়; desktop background-এর জন্য।
