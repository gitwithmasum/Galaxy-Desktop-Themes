# Galaxy Command Center for Rainmeter

Copy this entire folder into Rainmeter's Skins folder. Refresh all, then load `CommandCenter.ini` from Rainmeter Manage. Run alongside `MasumGalaxyTaskbarStars` if desired.

Edit `[Variables]` at the top of the INI to change your displayed name, city and latitude/longitude, and four links. Dhaka is the default. An active internet connection is required only for current weather (Open-Meteo); hardware stats and clock work locally. Refresh after editing. The panel resets to `(24,80)` on each skin refresh. Unload from Manage to remove it.
